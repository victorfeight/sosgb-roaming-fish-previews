# Roaming Fish Previews

Animal Crossing-inspired fishing for **STORY OF SEASONS: Grand Bazaar** on PC.
Fish shadows swim around each pool before you cast, approach your bobber,
and nibble before the game's fishing minigame begins.

- Finite schools sized to each pool, using the game's fish eligibility rules.
- Catch the fish you target; empty casts wait until you reel them in.
- Fish turn toward the bobber and approach headfirst before nibbling.
- Nearby fish scatter from hooks, running footsteps, and jumping into water.
- Swimming includes body bending, gradual turning, and acceleration.
- Caught fish recover slowly so you can gradually drain a pond.

## Install

1. Install and initialize **BepInEx 6 Unity IL2CPP x64** for the game.
   The old `6.0.0-pre.1` release is unsuitable.
2. Close the game and download `RoamingFishPreviews-v0.15.2.zip` from
   [Releases](https://github.com/victorfeight/sosgb-roaming-fish-previews/releases).
3. Extract it into the game directory and merge the `BepInEx` folder.

The log should show `Roaming Fish Previews 0.15.2 loaded`.
Settings are in `BepInEx/config/com.vic.sosgb.roamingfishpreviews.cfg`.
The preset uses 4-12 fish per pool, up to 18 loaded visuals, and recovery
of one missing fish per pool every 120 seconds.

To uninstall, remove `BepInEx/plugins/RoamingFishPreviews` and its config.
The mod does not write saves or change original game assets.

## Optional mesh flex

Some native meshes cannot be edited directly. To enable bending for all five
fish shadow classes, generate writable meshes from your own game installation:

```powershell
python -m pip install -r tools/requirements-extraction.txt
python tools/extract_writable_fish_meshes.py --game "C:\Program Files (x86)\Steam\steamapps\common\STORY OF SEASONS Grand Bazaar" --output "C:\Program Files (x86)\Steam\steamapps\common\STORY OF SEASONS Grand Bazaar\BepInEx\plugins\RoamingFishPreviews\meshes"
```

Extracted game meshes are excluded from the repository and release ZIP.

## Build

Requires .NET 6 and the interop assemblies generated by BepInEx:

```powershell
dotnet build src/RoamingFishPreviews/RoamingFishPreviews.csproj -c Release -p:GameDirectory="C:\Program Files (x86)\Steam\steamapps\common\STORY OF SEASONS Grand Bazaar"
powershell -ExecutionPolicy Bypass -File scripts/package-release.ps1
```
