Roaming Fish Previews v0.15.1

Requirements:
- STORY OF SEASONS: Grand Bazaar (Steam)
- Current BepInEx 6 Unity IL2CPP x64 build

Install:
1. Close the game.
2. Extract this archive into the game directory.
3. Merge the included BepInEx folder when prompted.
4. Start the game and check BepInEx/LogOutput.log for version 0.15.1.

Uninstall:
Delete BepInEx/plugins/RoamingFishPreviews and
BepInEx/config/com.vic.sosgb.roamingfishpreviews.cfg.

The mod does not modify original game assets or save files.
